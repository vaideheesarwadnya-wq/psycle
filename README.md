# 🌸 Psycle – Your Cycle Your Space

**Psycle** is a Java-based desktop application designed to help users track and understand their menstrual cycles, maintain daily health logs, and gain insights into their cycle patterns through a simple and user-friendly interface.

The application focuses on providing a comfortable, organized, and privacy-conscious space for menstrual health tracking.

---

## ✨ Features

- **Welcome Page** – A friendly introduction to the application.
- **Dashboard** – Get an overview of your cycle and important information.
- **Cycle Calendar** – View and track menstrual cycle dates.
- **Daily Log** – Record daily symptoms, moods, and personal notes.
- **Cycle Phases** – Understand the different phases of the menstrual cycle.
- **Insights** – View useful information based on recorded cycle data.
- **Settings** – Customize application preferences.
- **Reports** – Generate reports of tracked information.

## 🚀 Installation and Setup

### Option 1: Download the Windows Application

You do not need to install Java separately when using the bundled Windows version.

1. Visit the [GitHub Releases](https://github.com/vaideheesarwadnya-wq/psycle/releases/tag/v1.0.0) page.
2. Download `Psycle-Portable-Windows.zip`.
3. Extract the downloaded ZIP file.
4. Open the extracted `Psycle` folder.
5. Double-click `Psycle.exe`.

**Requirements:** Windows 10/11 (64-bit).

## 🔒 Privacy

Psycle is designed with privacy in mind. Personal tracking information is stored locally by the application rather than requiring a cloud account.

Keep your application data files safe and make backups when needed.

## 🎯 Project Objective

The objective of Psycle is to create an accessible and easy-to-use desktop solution for menstrual cycle tracking, helping users maintain consistent records and better understand their personal cycle patterns.
